# SEO — Reference

## How Pakistani users actually search

Query patterns differ from Western English search. Account for:

| Pattern | Example |
|---------|---------|
| Roman Urdu | "sugar control kaise kare", "sugar ka ilaj" |
| Code-switched | "roti sugar level", "biryani diabetes ok hai" |
| "Sugar" for diabetes | "sugar patient diet" far outranks "diabetes diet" locally |
| Food-first | People search the food, not the condition |
| Question-form | "kya chawal kha sakte hain sugar mein" |
| Brand-of-test | "HbA1c test Chughtai", "sugar test rate Lahore" |

**"Sugar" is the single most important local vocabulary note.** Most Pakistani patients say and search "sugar", not "diabetes". Title tags can carry "diabetes" for authority while H2s and FAQs use "sugar" for match.

## Keyword → intent mapping

| Intent | Signals | Content type |
|--------|---------|--------------|
| Informational | "what is", "why does", "kaise" | Blog, guide |
| Commercial | "best", "program", "cost", "review" | Landing, comparison |
| Navigational | Brand terms | Homepage, landing |
| Transactional | "book", "join", "sign up" | Landing, enrollment |

Match the page type to intent. An informational query landing on a sales page bounces.

## Banned terms with high search volume

Some of the highest-intent queries in this niche are terms we restrict:

| Query | Rule |
|-------|------|
| "reverse diabetes" | B2C landing/ads only, with remission defined on-page. Never a blog H1. |
| "cure diabetes" | Never targeted. Not in title, H1, meta, or slug — anywhere. |
| "diabetes cure in 30 days" | Never |

**You may target the *intent* without the term.** Someone searching "reverse diabetes" wants to know if improvement is possible — answer that with "remission", honestly. Don't chase the keyword into a claim.

## Cannibalisation check

Before assigning a primary keyword:

1. List existing published pieces
2. Check none already targets it or a near-variant
3. If overlap exists → either consolidate into one stronger piece, or re-angle this one

Two pieces competing for one query is worse than one piece.

## Featured snippet targeting

- 40–60 words
- Direct answer in the first sentence
- Placed early, right after the intro
- Plain sentences, no lists inside it
- Answers the H2 question above it literally

## Meta description patterns

| Good | Why |
|------|-----|
| "Same rice, two meals, two different numbers. Here's what pairing does to your blood sugar — and the one swap to try tonight." | Specific, curiosity + payoff, keyword present |

| Bad | Why |
|-----|-----|
| "Learn about glycemic load and diabetes management in this comprehensive guide." | Generic, no reason to click |
| "Reverse your diabetes fast with these secrets!" | Banned terms, hype |

## Data honesty

If no keyword tool is connected: **say so**. Reason from intent, local vocabulary, and competitor page titles. Never state a volume or difficulty figure you haven't measured — it will be treated as real and planned against.

## What you don't do

- Write the article (that's `writing`)
- Source medical claims (that's `medical-research`)
- Override a safety rule for ranking (never)
