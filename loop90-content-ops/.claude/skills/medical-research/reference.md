# Medical Research — Reference

## Source evaluation

Before citing, check:

| Check | Fail = don't cite |
|-------|-------------------|
| Peer-reviewed and indexed? | Preprints only with an explicit "not yet peer-reviewed" label |
| Population relevant? | Note it if the study is not South Asian |
| Sample size meaningful? | n < 30 is Level C regardless of design |
| Funding disclosed? | Industry-funded single studies drop one level |
| Superseded? | Check for a newer meta-analysis first |
| Primary source? | Never cite a news article about a study — cite the study |

## South Asian specificity

Where it matters for this domain:

- South Asians develop T2D at lower BMI than European populations
- Higher visceral fat at equivalent BMI ("thin outside, fat inside" phenotype)
- Standard BMI thresholds under-detect risk — Asian-specific cutoffs exist
- Most remission trials (including DiRECT) were on largely European cohorts

**Always note when a finding comes from a non-South-Asian population.** This is the single most common way our content could mislead.

## Core reference set

| Source | Level | Use for | Don't use for |
|--------|-------|---------|---------------|
| DiRECT (Lean et al., 2018/2019) | A | Remission definition, weight-loss pathway, 12/24-month outcomes | Implying the same rates in a Pakistani cohort |
| Roy Taylor — twin cycle | A (outcomes) / C (mechanism) | Liver and pancreas fat mechanism | Presenting mechanism as proven outcome |
| ADA Standards of Care | Consensus | Thresholds, definitions, standard of care | Novel claims |
| Jason Fung — *The Diabetes Code* | C | Fasting framing | Any number |

## Reference count

2–5. Not fewer, not more.

- Fewer than 2 → under-researched, or the claim is too thin to publish
- More than 5 → the piece is too broad; split it

## Handling "no good evidence"

When the brief asks for something the evidence doesn't support:

1. Say so plainly in the memo
2. State what *is* supported nearby
3. Return to `chief-content-strategist` to re-angle

Never pad a thin claim with a mechanism study and Level C language to make it publishable. That's how "early evidence suggests" becomes marketing.

## Common failure modes

| Failure | Fix |
|---------|-----|
| Subgroup result stated as general | Numbers table carries "in that subgroup" |
| Relative risk presented as absolute | State both, or state absolute only |
| Mechanism presented as outcome | Label Level C, say "proposed mechanism" |
| Western population result applied silently | Desi context section names the gap |
| Author name used as evidence | Cite the study, not the person |
| A round number that isn't in the source | Numbers table only |

## What you don't do

- Voice, tone, or structure — that's `writing` and `editing`
- Deciding the angle — that's the strategist
- Scoring the draft — that's `editing` and `medical-safety`

You establish the factual boundary. Everyone else works inside it.
