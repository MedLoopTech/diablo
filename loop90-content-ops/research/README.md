# Research

Standards and templates for the `medical-research` skill.

| File | Purpose |
|------|---------|
| [evidence-levels.md](evidence-levels.md) | A/B/C/consensus definitions, citation format, approved source tiers, hedging table |
| [research-memo-template.md](research-memo-template.md) | Output format — one memo per brief, consumed by `writing` |

## The rule that matters most

Every number a writer uses must appear in the research memo's **numbers table**, with its exact approved wording. Nothing gets rounded, restated, or recalled from memory downstream.
