# Checklists

Pass/fail gates. Unlike rubrics (which score), a checklist blocks on any unchecked box.

| File | Run by | When |
|------|--------|------|
| [safety-checklist.md](safety-checklist.md) | `medical-safety` | After editing, before publishing |
| [pre-publish-checklist.md](pre-publish-checklist.md) | `publishing` | Final gate, after safety clears |

Order: `editing` scores the rubric → `medical-safety` runs the safety checklist → `publishing` runs the pre-publish checklist.
