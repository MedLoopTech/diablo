# Template — Short-Form Video (Reels / Shorts)

★★★★ 30–60 seconds. Disclaimer must be **both** spoken and on screen.

## Constraints

| Field | Value |
|-------|-------|
| Length | 30–60 seconds (~75–150 spoken words) |
| Hook | First 3 seconds |
| Reading level | Grade 6–8 spoken |
| Disclaimer | Verbal **and** on-screen text |
| Captions | Always — most viewing is muted |

## Script format

```
[0:00–0:03] HOOK
  On screen: [text]
  Voice: [line]

[0:03–0:15] SETUP
  On screen: [text]
  Voice: [lines]
  B-roll: [what's shown]

[0:15–0:45] PAYOFF
  On screen: [text]
  Voice: [lines]
  B-roll: [what's shown]

[0:45–0:60] ACTION + DISCLAIMER
  On screen: [action] + [disclaimer text]
  Voice: [action line] + [spoken disclaimer]

CAPTION (for the post):
HASHTAGS: 3–5
```

## Hooks that work

- "Ek roti kitni sugar barhati hai? Chalein dekhtay hain."
- "Your after-dinner number is high. Here's the 10-minute fix."
- "Stop doing this with your rice."

## Hooks to avoid

- "Doctors don't want you to know this"
- Anything promising a number
- Slow build-ups — the hook is the first 3 seconds, not the first 10

## Disclaimer wording (short form)

Spoken: *"Yeh general information hai — medical advice nahi. Apne doctor se zaroor baat karein."*

On screen: *General information, not medical advice. Talk to your doctor.*

## Required elements

- [ ] Hook lands in 3 seconds
- [ ] One idea only
- [ ] One action at the end
- [ ] Disclaimer spoken **and** on screen
- [ ] Captions supplied
- [ ] Desi food shown if food is the topic

## Never

- Medication content in short video — the format has no room for the nuance
- Before/after transformation reveals
- Fear hooks
- Claims that need a citation the format can't carry — if it needs a source, it needs a blog post instead
