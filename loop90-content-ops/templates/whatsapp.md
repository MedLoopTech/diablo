# Template — WhatsApp

★★★★★ Top-priority channel. This is where the patient actually is.

## Constraints

| Field | Value |
|-------|-------|
| Length | 300–600 characters ideal; hard ceiling ~1000 |
| Reading level | Grade 6–8 |
| Formatting | `*bold*`, `_italic_` only. No markdown headings, no tables |
| Links | One, shortened. Never bare UTMs in the visible text |
| Emoji | Sparingly — 0–2, functional not decorative |
| Disclaimer | Link to the disclaimer page whenever a medical claim appears |

## Structure

```
[Greeting — optional, natural]

[Hook: one line, specific, about them]

[Body: 2–4 short lines. One idea. Concrete desi example.]

[One action for today]

[Link if needed]
```

## Required elements

- [ ] One idea only — never two
- [ ] One action, doable today
- [ ] Desi food/context if food is mentioned
- [ ] Disclaimer link if any medical claim
- [ ] Scannable on a small screen without pinch-zoom

## Variants

**Nudge** (daily/weekly, in-program)
Short. Warm. Never guilt. Assume they've missed a day.

> Assalam o Alaikum Imran 👋
>
> Aaj ka breakfast log kar lein — 30 seconds lagte hain.
>
> Aur haan, kal ka miss ho gaya to koi baat nahi. Aaj se shuru.

**Educational**
One fact, one action.

> *Chawal ke saath ek cheez add karein.*
>
> Plain white rice sugar ko tezi se barhata hai. Lekin saath mein daal, sabzi ya salad ho — to woh spike halka ho jata hai.
>
> Aaj lunch mein chawal ke saath kachumber try karein.
>
> Yeh general guidance hai, medical advice nahi: loop90.com/disclaimer

**Lead capture**
Value first, ask second.

> Free guide: *Desi Diabetes Plate* — roti, chawal aur biryani ke saath sugar control karne ka simple tareeqa.
>
> No cost, no signup drama. Yahan se lein: [link]

**Escalation-adjacent**
Never diagnose. Route.

> Aapki reading 250 se upar hai. Yeh urgent hai — apne doctor se abhi rabta karein.
>
> Agar bohot buri tabiyat lag rahi ho to emergency services ko call karein.

## Never

- Medical advice without the disclaimer link
- Medication instructions of any kind
- Multiple CTAs
- Long paragraphs
- Guilt for missed logs
- Formatting the app can't render

## Urdu / code-switching

Patient persona supports Roman Urdu code-switching. Doctor and pharma personas do **not** — keep those in professional English.
