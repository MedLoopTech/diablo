# Diabetes Remission Domain Module

First content domain for Loop/90 Content Operations. Framework skills reference this folder via `domain: diabetes-remission` in content briefs.

## Files

| File | Purpose |
|------|---------|
| [medical-philosophy.md](medical-philosophy.md) | Domain extensions to CONSTITUTION.md |
| [topic-pillars.md](topic-pillars.md) | Ranked content pillars and subtopics |
| [banned-claims.md](banned-claims.md) | Terminology and claim restrictions |
| [competitor-positioning.md](competitor-positioning.md) | Market positioning |
| [personas/](personas/) | Audience profiles |

## Adding content for this domain

1. Set `domain: diabetes-remission` in content brief.
2. Load relevant persona from `personas/`.
3. Apply banned-claims rules before safety review.
4. Use desi food examples by default (roti, daal, biryani — not quinoa).

## Future domains

Copy this folder structure for `hypertension`, `pcos`, `fatty-liver`, etc. Framework skills unchanged.
