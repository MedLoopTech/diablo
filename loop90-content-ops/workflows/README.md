# Workflows

Multi-skill chains. Each names its stages, gates, and failure paths.

| Workflow | Use for |
|----------|---------|
| [blog-post-pipeline.md](blog-post-pipeline.md) | The canonical chain — one medical article, end to end |
| [campaign-launch.md](campaign-launch.md) | Multi-piece, multi-channel launch around one anchor |
| [rapid-response.md](rapid-response.md) | Reactive content — viral claims, news, recurring questions |
| [localization-pipeline.md](localization-pipeline.md) | Cleared English → Urdu / Roman Urdu |

## The rule common to all four

**No workflow removes a gate.** Campaign urgency, news timing, and translation convenience are not exceptions. Every piece needs a brief, medical content needs a memo, everything needs ≥ 85/100 and a `cleared` verdict, and product facts are verified rather than recalled — every time.

## Where to start

New to this repo? Read `blog-post-pipeline.md` first. The other three are variations on it.
