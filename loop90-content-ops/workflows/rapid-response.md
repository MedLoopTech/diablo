# Workflow — Rapid Response

For reactive content: a viral health claim, a news story, a competitor announcement, a patient question that keeps recurring.

**Urgency compresses the timeline. It does not remove a single gate.**

---

## Shape

```
0-30 min    ceo + strategist    is this worth responding to?
30-90 min   medical-research    memo (compressed, same standard)
90-150 min  writing             draft
150-180 min editing + safety    score + verdict
180-200 min publishing          verify facts + ship
```

Roughly 3 hours. That is the floor for medical content, not a target to beat.

---

## 1. The response decision (first 30 minutes)

Most reactive opportunities should be declined. Answer all four:

| Question | If no |
|----------|-------|
| Does this touch a pillar we own? | Don't respond |
| Can we say something true and useful others aren't? | Don't respond |
| Is there evidence at any level to support our position? | Don't respond |
| Would we still want this published in six months? | Don't respond |

**Silence is a valid response.** Publishing a rushed, thin piece to be timely costs more than missing the moment.

---

## 2. Compressed research

Same standard, narrower scope:

- One question, not a survey
- 2–3 references minimum still applies
- Numbers table still mandatory
- Counter-evidence still mandatory
- If the evidence isn't there in 60 minutes, it probably isn't there — decline

**Never** compress by skipping the memo. Compress by narrowing the question.

---

## 3. Responding to a false viral claim

The most common rapid-response case: a WhatsApp forward claiming some remedy cures diabetes.

| Do | Don't |
|----|-------|
| Explain what's actually true | Mock the people who shared it |
| Name the mechanism honestly | Claim we have the alternative cure |
| Say what evidence exists and doesn't | Amplify the claim by repeating it in the headline |
| Give one useful action | Use the false claim as a keyword |

**Never repeat a false claim in a title, H1, or hook.** State the true thing; address the false one in the body.

Also never mock hakeem or herbal remedies or the people who trust them — `competitor-positioning.md` is explicit. Redirect gently.

---

## 4. Gates that still apply

Every one:

- [ ] Brief exists
- [ ] Memo exists for medical content
- [ ] Rubric ≥ 85/100
- [ ] Safety verdict `cleared`
- [ ] Product facts verified, not recalled
- [ ] Disclaimer correct for channel

If a gate can't be met in the window, the answer is **don't publish**, not publish anyway.

---

## 5. Channel choice

Fast channels first — but the anchor still matters if the topic has legs:

| Situation | Channel |
|-----------|---------|
| Correcting a viral claim | WhatsApp + Instagram, blog if it recurs |
| News commentary | LinkedIn (professional) or blog |
| Recurring patient question | In-app Learn + WhatsApp |
| Competitor announcement | Usually: no response |

---

## 6. After the moment

If the piece was worth writing quickly, it's usually worth rebuilding properly:

- Reissue as a full anchor through `blog-post-pipeline`
- Add the depth the deadline didn't allow
- The rapid version links to it

---

## The escalation rule

If someone asks to skip a gate because of timing, the decision to publish non-compliant medical content is the founder's to make explicitly — not a skill's to make silently. Escalate; don't comply.
